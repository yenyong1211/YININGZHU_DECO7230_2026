# 头显测试后的调整

- 完成条件仍为红书在书包内部且松手约 0.4 秒。完成后关闭旧 Task2 面板，显示持续的完成画面、星级和重玩提示；原 RESTART 物品仍可使用。
- 红书相对初始位置左右各 0.5 米、前后各 0.22 米活动，抬升 0.12–0.25 米；移动速度上限从 0.3 改为 0.65 米/秒。抓住后停止逃跑。
- 新增 PlayerHeight，由 UIFlowManager 启动时添加。等待头显定位后，把眼睛高度对齐学习卡中心；保持水平位置和真实头部旋转。使用 XR 的 CameraFloorOffsetObject 调整，避免移动重力抵消升降。
- 按住左手柄 X 降低、Y 升高；每秒 0.35 米，可相对初始校准高度上下调整各 0.6 米。同时按下则不升降。头显上下看仍由真实转头控制。

验证：Unity 编辑器自动流程覆盖学习、Task1、抓书、松手装包、持续结束画面、重玩和超时。真实头显的 X/Y 输入、舒适高度及扩大后的追书难度仍需上机体验。
