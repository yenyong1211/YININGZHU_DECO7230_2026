## 7. Cross-participant Findings

| Finding | Evidence | Iteration Direction |
|---|---|---|
| Task 1 → Task 2 flow is broken | All participants experienced no correct/incorrect feedback after selecting the computer, and Task 2 did not appear automatically | Highest priority: implement task-state logic. Correct computer selection should show success feedback and automatically trigger 拿起书; wrong selections should show “Try again” |
| Explore-stage review is inconsistent | Only three objects displayed review cards and none of the room cards replayed pronunciation. P1–P5 noticed this directly or looked for more consistent review support | Add review cards to all key objects and add a replay audio button. Keep Explore as a deliberate rehearsal phase |
| Action words are harder than concrete nouns | P1, P3, P4 and P5 showed more hesitation with 找到 and 拿起 than with 书 or 电脑 | Teach actions with animation, gesture or a short visual demonstration |
| Successful task completion does not always mean language comprehension | P3 completed Task 1 partly through guessing; P1 also used object recognition more than full phrase comprehension | Add progressive hints and a short comprehension check |
| Low-VR users confuse Select and Grab | P1, P3 and P5 tried clicking before grabbing or hesitated over controller use | Add a short controller tutorial before the language tasks |
| Pinyin remains useful | P5 used Pinyin strongly; beginners also benefited from pronunciation support | Use progressive support: Learning = Chinese + Pinyin + English + audio; Explore = Chinese + Pinyin + audio; Mission = Chinese only |
| Interactive VR tasks are engaging | Across P1–P5, the most enjoyable moments involved interacting with objects rather than reading cards | Strengthen the Detective Training / mission framing rather than adding more static flashcards |

---

## 8. Recommended Iteration Priority

1. Fix the **Task 1 → Task 2** transition and add immediate correct / incorrect feedback.
2. Add vocabulary cards to every key interactive object in the room.
3. Add pronunciation replay to Explore-stage object cards.
4. Add visual demonstrations for action words, especially **找到** and **拿起**.
5. Add a short VR controller tutorial explaining **Select vs Grab**.
6. Use progressive language support across **Learning → Explore → Mission**.
7. Reframe the initial card section as **Detective Training** so the learning stage feels connected to the mission.

## 9. Short Analysis Paragraph for the Report

Testing showed that the prototype successfully encouraged participants to connect Chinese vocabulary with physical objects and VR actions, but several interaction and feedback problems interrupted the intended learning flow. Concrete nouns such as **书** and **电脑** were generally easier to remember than action words such as **找到** and **拿起**. The Explore stage was useful as a review opportunity, but only three objects displayed vocabulary cards and the cards did not include pronunciation audio.

The most significant usability issue was that completing Task 1 produced no correct / incorrect feedback and did not trigger Task 2, so participants could not tell whether the system had registered their action. In addition, some participants completed tasks through guessing or controller experimentation rather than clear language comprehension.

The next iteration should therefore prioritise reliable task-state transitions, immediate feedback, consistent object review cards with audio, visual support for action vocabulary, and a short controller tutorial.
